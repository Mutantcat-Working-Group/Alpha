# 2026-09-16-session-format-v4

English | [中文](2026-09-16-session-format-v4.zh.md)

## Summary

Session format V4 replaces the V3 plugin wrapper around message sources with producer-owned source kinds, carries the system prompt as a logged `system/message` instead of a request-header field, adds logged developer messages as a durable event, and raises the writer version to 4.

<a id="compatibility"></a>
## Compatibility

Readers accept V3 logs through the adjacent format migration, which lifts historical plugin-wrapped sources to the producer kinds that own them and namespaces extension types this build does not declare under a `plugin:` identity. Unknown source kinds are preserved rather than rejected, so later producer-owned kinds stay same-version additions. The writer emits V4 only and does not downgrade; any further structural change requires a higher writer version with its own header transition.

<a id="verification"></a>
## Verification

The format migration specs replay the recorded V3 corpus into V4 and compare every migrated artifact with its released expectation; catalog and persistence specs compare the current declarations with this acknowledgement; client projection, subagent catalog, and session-query specs cover the producer-owned source kinds and the developer-message event end to end.
